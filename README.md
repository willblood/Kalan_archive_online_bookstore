# 📚 Kalan Archive – Online Bookstore Platform

Kalan Archive is a modern, responsive online bookstore that allows users to purchase handbooks and ebooks, while providing admins with full control over inventory, orders, users, and analytics. The platform also features an AI-powered chatbot for semantic book recommendations using the **Cohere API**.

---

## 🚀 Features

### 🛒 Customer Features
- Browse and purchase physical and digital books
- Secure Gmail-based authentication
- Real-time chat with **Kalan AI** for book recommendations
- View order history and receive email notifications
- Responsive design for desktop, tablet, and mobile

### 🛠️ Admin Features
- Add, update, and delete books
- Manage orders and customers
- View e-commerce analytics and reports

---

## 🤖 AI-Powered Chatbot
- Integrated **Cohere API** for semantic search and natural language book recommendations  
- Example: _“Can you suggest books on time management and self-discipline?”_

---

## 🔧 Tech Stack

### Frontend:
- HTML, CSS, JavaScript
- Bootstrap 5
- Swiper.js (interactive sliders)

### Backend:
- PHP 8+
- Laravel Framework
- MySQL (managed via MySQL Workbench)

### APIs & Integrations:
- **Cohere API** – Semantic search & recommendations
- **Gmail OAuth API** – One-click login
- **Mailtrap API** – Transactional email testing & delivery
- **Google Maps API** – Physical location display
